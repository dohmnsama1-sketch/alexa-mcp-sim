# Changelog

## 0.2.0 (2026-10-22)
- MCP Apps `tools/call` from cards, so touch actions such as "Mark given" work. The host adds the current speaker and the trace marks these calls as `(touch)`. New `/api/tap` endpoint.
- Bundled interaction models: `--model careloop`.
- GitHub Actions CI on Python 3.11–3.13. 21 tests, 90% coverage.

## 0.1.0 (2026-10-22)
- First release: Echo Show-style screen, Web Speech voice in and out, speaker profiles, MCP Apps host, live trace, offline interaction-model planner and Amazon Bedrock planner.
